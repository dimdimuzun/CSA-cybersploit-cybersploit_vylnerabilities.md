# Перелік виявлених вразливостей у CTF MoneyBox

## 1. Анонімний FTP-доступ (порт 21)
- Доступ дозволений без пароля.
- Можливість перегляду та скачування файлів.

## 2. Зберігання чутливих даних у FTP
- У відкритому каталозі знаходиться зображення зі стеганографічно прихованими даними.

## 3. Приховані директорії та підказки у вихідному HTML-коді
- Доступні каталоги `blogs` та `S3ct3r-T3xt`.
- Ключ `3xtr4ctd4t4` знаходиться у вихідному коді сторінки.

## 4. Стеганографічно приховані конфіденційні дані
- У зображенні приховано файл `data.txt` з інформацією про користувача `renu`.
- Дані містять повідомлення про слабкий пароль.

## 5. Слабкий пароль користувача (брутфорс через rockyou.txt)
- Пароль `987654321` легко перебирається за допомогою `hydra`.

## 6. Небезпечні SSH-налаштування
- Користувач `renu` може увійти через SSH без додаткових обмежень.
- Публічний ключ `renu` збережений у `.ssh/authorized_keys` іншого користувача — `lily`.

## 7. Небезпечні sudo-привілеї
- Користувач `lily` може виконувати `sudo perl` без пароля.
- Це дозволяє виконати команду для ескалації привілеїв до root:
  ```sh
  sudo perl -e 'exec "/bin/bash";'
  ```

## 8. Зберігання прапорців та даних у доступних домашніх директоріях
- Користувачі мають доступ до файлів один одного.
- Конфіденційні файли розміщено у відкритих директоріях.
