# MoneyBox

В цьому документі наведено розгорнуте пояснення до завдання **Capture the Flag (CTF)**, опубліковане на сайті [**VulnHub**](https://www.vulnhub.com/entry/moneybox-1,653/) автором **"Kirthik_T"**.
Відповідно до наданої автором інформації, рівень складності цього CTF — **ЛЕГКИЙ**, а мета — отримати **root-доступ** до цільової машини та знайти **файли-прапорців**.

Для проходження цього CTF необхідно мати **базові знання команд Linux** та **навички використання інструментів для тестування на проникнення**.
Завантажити оригінал CTF можна [тут](https://download.vulnhub.com/moneybox/MoneyBox.ova).

> ⚠️ **Примітка**: Для запуску всіх віртуальних машин було використано [**Oracle VirtualBox**](https://www.virtualbox.org/).
> Для проходження CTF використано [**Kali Linux**](https://www.kali.org/docs/introduction/download-official-kali-linux-images/) як атакуючу машину.
> Використані методики призначені **виключно для освітніх цілей**.<br>
> **Відповідальность за їх застосування проти будь-яких інших цілей буде визначатись відповідно чинному законодавству.**

---

MoneyBox з полігону Offensive Security є машиною середньої складності, яка призначена для тренування, перевірки надійності мережі та налаштування привілеїв.
Завдання є середньої складності з всебічним випробуванням для відточування навичок тестування на проникнення, пропонуючи реальні сценарії та вектори атак.
У цьому завданні ми розпочнемо з аналізу, щоб виявити відкриті порти та доступні сервіси, продовжимо ідентифікувати вразливостей і, нарешті, використаємо ці вразливості для отримання root-доступу.
На завершення розглянемо деякі рекомендації для підвищення стійкості та надійності віртуальної машини.

## **Короткий огляд кроків вирішення CTF**
1. Завантажити та запустити цільову машину та інструмент для дослідження.
2. Отримати **IP-адресу цільової машини** за допомогою **netdiscover**.
3. Просканувати **відкриті порти** за допомогою **nmap**.
4. Дослідити **FTP-сервіс** на 21 порті.
5. Скачати та дослідити графічне зображення.
6. Дослідити **HTTP-сервіс** на 80 порті. Провести огляд файлової системи web серверів та виявити приховані файли та папки.
7. Знайти зображення, отримати приховані дані.
8. Проаналізувати приховані дані. Виявити вразливості у цільовій системі.
9. Налаштувати файл зі списком ключових слів.
10. Дослідити облікові записи користувачів. Визначити їх паролі.
11. Виявити конфіденційні файли на цільовому комп'ютері. Проаналізувати виявлені файли на наявність корисної інформації.
12. Дослідити файли інших користувачів системи.
13. Дослідити шляхи для підвищення привілеїв. Отримати **root-доступу** до цільової системи.

### **Крок 3: Сканування відкритих портів за допомогою nmap**
Використаємо nmap для сканування отриманої IP-адреси на наявність **відкритих портів** та **запущених сервісів**.
Для цього використовуємо команду з ключем **-A** для виконання агресивного сканування.
Ця опція активує агресивні параметри сканування. Вона виконує комплексне сканування, яке включає:
- **виявлення ОС**; визначає операційну систему цільового об'єкта;
- **виявлення версій**; визначає версії служб, що працюють на відкритих портах;
- **сканування скриптів**; запускає скрипти за замовчуванням для збору додаткової інформації про цільовий об'єкт;
- **трасування**; відображає шлях, яким пакети досягають цільового об'єкта.

```sh
nmap -A 192.168.6.147
```

📌 **Результат**:
- Відкрито порт **21 (FTP)**.
- Відкрито порт **22 (SSH)**.
- Відкрито порт **80 (HTTP, Apache Server)**.<br>
![targetport.png](./moneybox/targetport.png)

### **Крок 7: Аналіз зображення, отримання прихованих даних**
Дослідимо зображення кота на наявність в ньому прихованої інформації.
Цей спосіб збереження даних називається **стеганографією**.<br>

**Стеганографія** — це розділ криптології метою якого є приховування самого факту існування таємної інформації шляхом її інтеграції в інші файли не змінюючи при цьому загального вигляду останніх.
Для приховуванн можуть бути використані мультимедійні файли, наприклад, зображення, аудіо, відео, офісні та навіть текстові документи.
Стеганографія використовує цифрові контейнери для передачі повідомлень, що робить їх непомітними для сторонніх осіб.<br>

Якщо зображення не показує нічого очевидного, в ньому можуть бути приховані дані.
Перевіримо наявність прихованих повідомлень за допомогою інструментів стеганографії.
Для цього використаємо **steghide** — популярний інструмент стеганографії, який дозволяє приховувати та витягувати дані у зображеннях та аудіофайлах.
Встановимо **steghide** за допомогою команди:

```sh
sudo apt install steghide
```

**Результат**:
Інструмент для вилучення прихованих даних встановлено.<br>
![steghideinstall.png](./moneybox/steghideinstall.png)

Скористаємося наступними параметрами команди **steghide**.
- Параметер **extract** вказує steghide спробувати отримати будь-які приховані дані.
- Прапорець **-sf** вказує на файл, який потенційно містить приховану інформацію.
В нашому випадку стеганографічним файлом є зображення **trytofind.jpg**.<br>

Також **steghide** може запропонувати нам ввести пароль.
В цьому випадку спробуємо ввести ключ **3xtr4ctd4t4**.
Отже виконаємо команду:

```sh
steghide extract -sf trytofind.jpg
```

**Результат**:
Наш ключ **3xtr4ctd4t4** спрацював і **steghide** повідомив нам, що приховані дані за зображенням було вилучено у файл з назвою **data.txt**.<br>

### **Крок 10: Підбір пароля користувача renu**
Спробуємо підібрати пароль по протоколу ssh за допомогою команди **hydra**.<br>
Це вбудований у **Kali Linux** інструмент, який використовується в кібербезпеці та тестуванні для швидкого підбору паролів методом брутфорс (перебору) у реальному часі.
**Hydra** підтримує понад 50 протоколів, включаючи SSH, FTP, HTTP, HTTPS, SMB.<br>

Спробуємо підібрати пароль користувачу на ім'я **renu**.
Скористаємося наступними параметрами команди **hydra**.<br>
- **hydra** це команда для запуску **hydra**, інструменту для злому паролів методом повного перебору;
- прапорець **-l renu** вказує ім'я користувача для входу, яке буде використовуватися для атаки повним перебором; в нашому випадку це ім'я користувача **renu**;
- прапорець **-P /usr/share/wordlists/rockyou.txt** вказує шлях до файлу зі списком паролів, який **hydra** використовуватиме для атаки; ми використовуємо **rockyou.txt**, який є популярним списком слів, що часто використовується для злому паролів;
- параметр **-f** вказує **hydra** зупинитися після першого успішного входу;
- параметр **192.168.6.147** задає цільову IP-адресу для служби SSH;
- параметр **ssh** вказує на протокол, по якому відбуватиметься вхід.

```sh
hydra -l renu -P /usr/share/wordlists/rockyou.txt -f 192.168.6.147 ssh .
```

📌 **Результат**:
Ми отримали пароль **987654321** користувача **renu**.<br>

### **Крок 13: Дослідження потенційних шляхів для підвищення привілеїв**
В домашньому профілі користувача **lily** перейдемо до папки **.ssh** та виведемо список файлів.
Виконаємо команди:

```sh
cd .ssh
ls
```

📌 **Результат**:
У папці **.ssh** присутній файл **authorized_keys**.<br>
![lilysshlist.png](./moneybox/lilysshlist.png)

Проаналізуємо вміст файлу **authorized_keys**.
Виконаємо команду:

```sh
cat authorized_keys
ls
```

📌 **Результат**:
У файлі **authorized_keys** зберігається публічний ключ користувача **renu**.
Це означає, що користувач **renu** може залогуватися під користувачем **lily**.<br>
![lilyauthorizedkeys.png](./moneybox/lilyauthorizedkeys.png)

Увійдемо в систему як користувач **lily** використовуючи **ssh**.
Виконаємо команду:

```sh
ssh lily@192.168.6.147
```

📌 **Результат**:
Ми увійшли в цільову систему по протоколу **ssh** як **lily** без введення пароля.
При першому вході вводимо **yes** для підтвердження операції.<br>
![lilyaccessdone.png](./moneybox/lilyaccessdone.png)

Перевіримо права на виконання команди **sudo**.
Виконаємо команду:

```sh
sudo -l
```

📌 **Результат**:
Ми побачили, що користувач **lily** має права **sudo** і може виконувати команди **perl** від імені **root** без введення пароля.<br>
![lilyaccesssudo.png](./moneybox/lilyaccesssudo.png)

Виконаємо команду **perl** з наступними параметрами:
- утиліта **sudo** виконує команду з правами root;
- параметр **perl -e** вказує на необхідність виконати код на мові **Perl**, який буде наданий в аргументі командної стрічки;
- операція **'exec "/bin/bash";'** є кодом на мові **Perl**, який завантажує нову оболонку **/bin/bash** від імені користувача **root**.
Отже виконаємо команду:

```sh
sudo perl -e 'exec "/bin/bash";' .
```

📌 **Результат**:
Ця команда запустила нову оболонку **bash** з правами **root**.
Ми отримавши доступ до всієї системи та можемо виконувати будь-які дії.
Оскільки задана директива **NOPASSWD**, то **sudo** не вимагає введення пароля користувача **lily**.<br>
![rootaccessdone.png](./moneybox/rootaccessdone.png)

Розглянемо список файлів в профілі користувача **root**.
Виконаємо команди:

```sh
cd ~
ls -al
```

📌 **Результат**:
У списку ми побачили приховану папку **.local** та файл **.root.txt**.<br>
![roothomelist.png](./moneybox/roothomelist.png)

Виведемо вміст файлу **.root.txt**.
Виконаємо команду:

```sh
cat .root.txt
```

📌 **Результат**:
Ми отримали фінальний файл з прапорцем.<br>
![rootdoneflag.png](./moneybox/rootdoneflag.png)

✅ **Фінальний прапорець отримано! CTF завершено!** 🎯
