# Мапінг виявлених активностей та конфігураційних недоліків на матрицю **MITRE ATT&CK** (версія для корпоративних систем — Enterprise).

Цей мапінг показує повний ланцюжок дій (Kill Chain) від первинної розвідки до отримання максимальних привілеїв адміністратора.

---

### 1. Reconnaissance (Розвідка)

* **T1595 — Active Scan (Активне сканування):**
* **Експлуатація:** Використання інструменту `nmap` для повного сканування портів цільової IP-адреси (`10.0.2.28`) з метою виявлення активних служб (SSH, HTTP, SMB, MySQL, IRC).


* **T1595.002 — Vulnerability Scanning (Сканування вразливостей):**
* **Експлуатація:** Запуск сканерів вебдодатків (`dirb`, `nikto`, `gobuster`) для автоматизованого пошуку прихованих папок, скриптів та вразливостей на вебсервері Apache.



### 2. Discovery (Збір інформації / Розвідка всередині системи)

* **T1083 — File and Directory Discovery (Пошук файлів та директорій):**
* **Експлуатація:** Інструмент `dirb` успішно виявив відкриті для перегляду директорії (Directory Listing) на вебсервері, такі як `/old/`, `/test/`, `/wp/`, а також чутливий файл конфігурації контенту `info.php`.


* **T1046 — Network Service Discovery (Збір інформації за мережевими службами):**
* **Експлуатація:** За допомогою `enum4linux` було зібрано детальну інформацію про конфігурацію служби Samba (робоча група WORKGROUP, політика паролів, наявні ресурси).


* **T1018 — Remote System Discovery (Пошук віддалених систем):**
* **Експлуатація:** Перегляд повідомлень на форумі WordPress допоміг виявити логіку залишених адміністратором налаштувань за замовчуванням.



### 3. Initial Access (Первинний доступ)

* **T1078 — Valid Accounts (Використання чинних облікових записів):**
* **Експлуатація:** Зловмисник зміг підключитися до мережевої шари Samba (`//10.0.2.28/share$`), використовуючи анонімний гостьовий вхід (Null Session) без введення логіна та пароля.


* **T1589 — Gather Victim Identity Information (Збір ідентифікаційних даних жертви):**
* **Експлуатація:** Через RID cycling під час роботи `enum4linux` було примусово перераховано локальних користувачів та виявлено ім'я реального користувача системи — `togie`.



### 4. Credential Access (Доступ до облікових даних)

* **T1552.001 — Credentials In Files (Паролі у файлах):**
* **Експлуатація:** Усередині змонтованої відкритої папки Samba було знайдено текстовий файл `deets.txt` та файл конфігурації `wp-config.php`, які містили конфіденційну інформацію та паролі.


* **T1110.001 — Brute Force: Password Guessing (Підбір паролів):**
* **Експлуатація:** Маючи чітке ім'я користувача (`togie`), зловмисник запустив утиліту `hydra` для проведення атаки перебором (Brute Force) по службі SSH, використовуючи популярний словник `rockyou.txt`. Це дозволило скомпрометувати слабкий пароль `12345`.



### 5. Execution (Виконання команд)

* **T1059.004 — Command and Scripting Interpreter: Unix Shell (Командний інтерпретатор):**
* **Експлуатація:** Після успішного підбору пароля зловмисник виконав віддалений вхід через SSH (`ssh togie@10.0.2.28`) та отримав інтерактивний доступ до Unix-сесії (`/bin/bash`) в системі під виглядом легітимного користувача.



### 6. Privilege Escalation (Підвищення привілеїв)

* **T1548.003 — Abuse Mechanism: Sudo and Sudo Caching (Зловживання механізмом Sudo):**
* **Експлуатація:** Перевірка дозволів за допомогою команди `sudo -l` показала надлишкову конфігурацію прав користувача. Через недбалість адміністратора ("LazyAdmin") обліковий запис мав право виконувати інструкції з найвищими привілеями, що дозволило миттєво підняти права до суперкористувача через команду `sudo -i` і отримати повний контроль над системою (`root`).
