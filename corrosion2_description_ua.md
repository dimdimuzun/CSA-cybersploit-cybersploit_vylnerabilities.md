# Corrosion2

В цьому документі наведено розгорнуте пояснення до завдання **Capture the Flag (CTF)**, опубліковане на сайті [**VulnHub**](https://www.vulnhub.com/entry/corrosion-2,745/) автором **"Proxy Programmer"**.
Відповідно до наданої автором інформації, рівень складності цього CTF — **СЕРЕДНІЙ**, а мета — отримати **root-доступ** до цільової машини та знайти **файли-прапорців**.

Для проходження цього CTF необхідно мати **базові знання команд Linux** та **навички використання інструментів для тестування на проникнення**.
Завантажити оригінал CTF можна [тут](https://download.vulnhub.com/corrosion/Corrosion2.ova).

> ⚠️ **Примітка**: Для запуску всіх віртуальних машин було використано [**Oracle VirtualBox**](https://www.virtualbox.org/). Для проходження CTF використано [**Kali Linux**](https://www.kali.org/docs/introduction/download-official-kali-linux-images/) як атакуючу машину. Використані методики призначені **виключно для освітніх цілей**.<br>
> **Відповідальность за їх застосування проти будь-яких інших цілей буде визначатись відповідно чинному законодавству.**

---

Proxy Programmer’s Corrosion є машиною середньої складності призначеної для тренування, перевірки надійності мережі та налаштування привілеїв.
У цьому завданні ми виконяємо ряд кроків для компрометації машини та розглянемо деякі рекомендації для підвищення її стійкості та надійності.

## **Короткий огляд кроків вирішення CTF**
1. Завантажити та запустити цільову машину та інструмент для дослідження.
2. Отримати **IP-адресу цільової машини**.
3. Просканувати **відкриті порти** за допомогою **nmap**.
4. Дослідити **HTTP-сервіси** на визначених портах. Провести огляд файлової системи web серверів та виявити приховані файли.
5. Отримати доступ до закодованих файлів захищеного архіву з даними конфігурації web сервера.
6. Проаналізувати виявлені файли на наявність корисної інформації.
7. Створити веб аплікацію для зворотного зв'язку.
8. Завантажити код на веб сервер для проникнення на цільову машину.
9. Виявити конфіденційні файли на цільовому комп'ютері.
10. Дослідити облікові записи користувачів.
11. Визначити паролі користувачів.
12. Дослідити шляхи для підвищення привілеїв. Отримати **root-доступу** до цільової системи.

### **Крок 3: Просканувати відкриті порти за допомогою nmap**
Використаємо nmap для сканування отриманої IP-адреси на наявність **відкритих портів** та **запущених сервісів**.

```sh

```

📌 **Результат**:

- Відкрито порт **80 (HTTP, Apache Server)**.
- Відкрито порт **8080 (HTTP, Tomcat Server)**.<br>

### **Крок 11: Визначення пароля користувача randy**
