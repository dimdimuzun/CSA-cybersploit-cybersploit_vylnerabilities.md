# Мапінг (відповідність) виявлених уразливостей та слабких місць на актуальні категорії **OWASP Top 10**:

---

### 1. A01:2021-Broken Access Control (Порушення контролю доступу)

* **Виявлена проблема:** Наявність відкритого списку файлів у директоріях вебсервера (Directory Listing або **Directory Is Listable**). Інструмент `dirb` зафіксував, що директорії `/apache/`, `/javascript/`, `/old/`, `/test/`, `/wp/` є відкритими для вільного перегляду.
* **Виявлена проблема:** Зайві відкриті адміністративні інтерфейси та скрипти, доступні без автентифікації (наприклад, `info.php` із повним виводом конфігурації `phpinfo()`).

### 2. A04:2021-Insecure Design (Ненадійний дизайн / Архітектурні недоліки)

* **Виявлена проблема:** Зберігання конфіденційних файлів та резервних копій у кореневих або загальнодоступних мережевих директоріях. Залишення файлів конфігурації (`wp-config.php`) та файлів із текстовими нотатками (`deets.txt`) у відкритій для читання мережевій шарі Samba (`//10.0.2.28/share$`) дозволило зловмиснику отримати облікові дані без жодного зламу.

### 3. A05:2021-Security Misconfiguration (Неправильна налаштування безпеки)

* **Виявлена проблема:** Занадто надлишкові привілеї для звичайного користувача в системі Linux (Слабке налаштування `sudo`). Користувач `togie` мав дозвіл виконувати команди через `sudo -l` у такий спосіб, що дозволило адміністратору ("Lazy Admin") просто безперешкодно отримати root-доступ через команду `sudo -i`.
* **Виявлена проблема:** Небезпечні налаштування служби SMB (Samba). Було дозволено анонімний вхід (NULL Session / Guest account) з пустим логіном та паролем (`''`), що надало можливість провести повну розвідку системи (`enum4linux`), дізнатися імена локальних користувачів та змонтувати внутрішні папки.
* **Виявлена проблема:** Залишені дефолтні налаштування (Default accounts) для CMS WordPress, що дозволило припустити наявність стандартного адмін-акаунту.

### 4. A07:2021-Identification and Authentication Failures (Збої ідентифікації та автентифікації)

* **Виявлена проблема:** Використання слабких, передбачуваних або скомпрометованих паролів. Пароль локального користувача `togie` для доступу по SSH був підібраний утилітою `hydra` за стандартним і загальновідомим словником `rockyou.txt`. Самим паролем виявився вкрай слабкий набір символів: `12345`.

---

### Резюме для безпеки системи:

Ця машина є класичним прикладом атаки, де зловмиснику не знадобилося експлуатувати складні бінарні вразливості або zero-day. Увесь ланцюжок атаки (Kill Chain) — від отримання первинного доступу до підвищення привілеїв до `root` — став можливим виключно через **Security Misconfiguration (A05)** та **Identification and Authentication Failures (A07)**.
