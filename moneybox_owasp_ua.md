
# Маппінг вразливостей MoneyBox на OWASP Top 10

## OWASP Top 10 (версія 2021)

| Вразливість | Опис | Відповідний OWASP Top 10 пункт |
|-------------|------|--------------------------------|
| Анонімний FTP-доступ | Дозволяє неавторизований доступ до файлів | **A01:2021 – Broken Access Control** |
| Зберігання конфіденційних даних у відкритому FTP | Дані не захищені, доступні будь-кому | **A02:2021 – Cryptographic Failures** |
| Приховані каталоги в HTML (blogs, S3ct3r-T3xt) | Інформаційні підказки в коді | **A05:2021 – Security Misconfiguration** |
| Стеганографічні приховані дані з чутливою інформацією | Ненадійне управління конфіденційними даними | **A02:2021 – Cryptographic Failures** |
| Слабкий пароль користувача (987654321) | Легко підбирається словником | **A07:2021 – Identification and Authentication Failures** |
| Відсутність обмежень SSH доступу | Недостатні засоби контролю доступу | **A01:2021 – Broken Access Control** |
| Публічний ключ одного користувача в authorized_keys іншого | Можливість несанкціонованого доступу | **A01:2021 – Broken Access Control** |
| sudo perl без пароля (NOPASSWD) | Пряма ескалація привілеїв | **A05:2021 – Security Misconfiguration** |
| Доступ користувачів до чужих файлів | Некоректні файлові дозволи | **A01:2021 – Broken Access Control** |
| Прапорці та чутливі дані у звичайних директоріях | Недостатній захист даних | **A02:2021 – Cryptographic Failures** |
